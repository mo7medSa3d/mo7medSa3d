# Mohamed Saad — Portfolio (2027 Edition)

High-performance Next.js 15 + React 19 + Tailwind CSS + Three.js portfolio for Mohamed Saad (Data Scientist & Machine Learning Engineer).

## Quick Start

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Build & Typecheck

```bash
npm run typecheck
npm run build
npm run start
```

## Customize
- Update profile, projects, skills, and links in `constants/data.ts`.
- Replace `public/resume.pdf` or `public/images/*` to update assets.
