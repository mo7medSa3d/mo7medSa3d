### 🚀 Featured Engineering & ML Projects

#### ⚽ [FIFA Player Analytics Engine](https://github.com/hamo229)
> End-to-end predictive machine learning system predicting valuation tiers and performance benchmarks.
- **Architecture**: Ensembling with `Stacking Regressor`, `Random Forest`, `SVR`, and `KNN`.
- **Implementation**: Advanced data imputation, feature interaction scaling, and hyperparameter tuning.

#### 🚗 [Used Car Price Prediction & Sensitivity Analysis](https://github.com/hamo229)
> Scalable regression pipeline trained and validated on 72,000+ automotive listing records.
- **Highlights**: Rigorous sensitivity analysis, automated outlier detection, and log-transform pipelines.
- **Stack**: `Python`, `Scikit-Learn`, `Pandas`, `Matplotlib`.

#### 💳 [Home Equity Risk Segmentation Model](https://github.com/hamo229)
> Unsupervised credit risk assessment system extracting latent borrower solvency archetypes.
- **Architecture**: Dimensionality reduction via `PCA`, combined with `K-Medoids` clustering and fuzzy logic rules.
- **Application**: Portfolio default risk mitigation and customer risk tier classification.

#### 🧮 [Scratch ML: Gradient Descent & Regularization](https://github.com/hamo229)
> Pure mathematical implementation of Linear and Ridge Regression from first principles.
- **Focus**: Built strictly using `NumPy` matrix operations without high-level ML wrappers.
- **Analysis**: Convergence rate monitoring across dynamic learning schedules and L2 penalty tuning.
